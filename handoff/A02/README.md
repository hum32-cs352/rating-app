# A02 Local Test - Hum32@CS352, Team A02 The Innovators

## What this project is
Seven small Java classes (package `domain`) that model students, faculty,
course sections and office allocation records, plus a console driver
(`StudentDriver`) that checks every required behavior.

## Requirements
- JDK 17 or newer (check with `java -version` and `javac -version`)
- Windows (the runner is a `.bat` file)
- No external libraries and no internet connection needed

## Folder layout
Student_A02/
src/domain/ the 7 Java files
handoff/A02/ run script, input, expected output, test results
out/A02/ generated by the compiler (do not edit)

## How to run
1. Keep the folder structure unchanged.
2. Double-click `handoff/A02/run_student.bat`.
3. For a clean check, delete only the `out/A02` folder and run again.

The script compiles the files listed in `sources.txt`, then runs
`domain.StudentDriver` with `demo-input.txt` as input.

## Expected success message
All 14 lines starting with `[PASS]` appear, and the last line is:

    A02 READY | Identity + teaching relationships verified

The full expected output is in `expected_output.txt`.

If something fails, the script prints `A02 FAILED - read the error above.`
and the line above it names the check that failed.

## Files in handoff/A02
- `sources.txt`: the 7 Java files to compile, one path per line
- `demo-input.txt`: test input (seat number, name, section)
- `expected_output.txt`: output of a successful run
- `test-results.txt`: observed runs from two laptops
- `run_student.bat`: compile-and-run script
