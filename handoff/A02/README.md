# A02 - Student identity and teaching assignments
Hum32@CS352 | Team A02 The Innovators

A small Java module (package `domain`) that models students, faculty, course
sections and office allocation records, with console drivers that check the
required behaviour. Students can carry an optional enrolment number.

## Requirements
- JDK 17 or newer (check with `java -version` and `javac -version`)
- Windows with PowerShell (the runners are `.bat` files)
- No external libraries and no internet connection needed

## Folder layout
```
rating-app/
  src/domain/     the nine Java files
  handoff/A02/    runner, input, expected output, test results, diagrams
  out/A02/        generated by the compiler (do not edit or commit)
```

## How to run
Run these from the `rating-app` folder, one at a time. Press a key when a
script asks.

```
.\run.bat
.\handoff\A02\run_student.bat
java -cp out\A02 domain.FacultyDriver
java -cp out\A02 domain.SectionOfficeDriver
```

`run_student.bat` compiles the files listed in `handoff\A02\sources.txt` into
`out\A02` and runs `StudentDriver` with `demo-input.txt`. It must run before
the two `java -cp` commands, because they use the compiled classes.
For a clean run, delete only the `out\A02` folder and run again.

If a check fails, the driver stops with an `AssertionError` that names the
failed check.

## Java files (src/domain)
- `Student.java`: immutable student (seat number, name, section, optional
  enrolment number)
- `SectionName.java`: enum A, B, C
- `Faculty.java`: faculty member
- `FacultyType.java`: enum PERMANENT, VISITING
- `Section.java`: course section with an optional faculty
- `Office.java`: record linking one Student to one Section
- `StudentDriver.java`: identity, enrolment and teaching-relationship checks
- `FacultyDriver.java`: enum switch demonstration and invalid-value handling
- `SectionOfficeDriver.java`: shared Faculty references and Office checks

## Enrolment number
- `Student(seatNo, name, sectionName)` stores no enrolment number (`null`).
- `Student(seatNo, name, sectionName, enrolmentNo)` accepts `null` or text.
- A non-null enrolment number must not be blank or have leading/trailing
  whitespace (`IllegalArgumentException`); otherwise the exact text is kept.
- `getEnrolmentNo()` returns the stored value, including `null`.
- All four copy routes preserve it. `equals` and `hashCode` use the seat
  number only.

## Files in handoff/A02
- `sources.txt`: the nine Java files to compile, one path per line
- `demo-input.txt`: input for StudentDriver (seat number, name, section)
- `expected_output.txt`: output of a successful StudentDriver run
- `test-results.txt`: observed test runs and results
- `run_student.bat`: compile-and-run script

- `section_office_objects.drawio`: object diagram of the Section/Office references
- `student_api_register.xlsx`: register of every public constructor and method
- `contributions.txt`: member credits
