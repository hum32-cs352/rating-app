# B05 Reflection Module

## How to run the demo
1. Install JDK 17.
2. Open Command Prompt in the rating-app folder.
3. Run: handoff\B05\run_demo.bat
4. Answer the questions the demo asks. Press Enter to skip a question.

The driver is src/domain/reflection/ReflectionDriver.java

## Missing dependencies
None.
